# Trading AI

Trading AI analyzes stocks, ETFs, and options using market data, fundamentals, technical indicators, and news sentiment, then runs LLM-driven agents that vote to produce trade recommendations. It manages a simulated portfolio via Alpaca paper trading and backtests strategies against historical data.

## Why this exists

A personal portfolio project demonstrating full-stack engineering and modern AI-agent orchestration.

## Tech stack

React + TypeScript + Tailwind + Recharts · FastAPI (Python) · PostgreSQL · Claude API + LangGraph · Finnhub / Alpaca / yfinance market data · pandas / NumPy · Alpaca paper trading · Docker + Render + GitHub Actions.
